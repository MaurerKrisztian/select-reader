How to use Select Reader

Reading

  1. Select text in any app.
  2. Press . Press it again on the same text to stop.
  3. Or paste text into this window with .

Closing the window keeps Select Reader running in the tray, so the shortcut keeps working. To stop it, use Quit (here or in the tray menu).

On Wayland, other apps don't pass shortcuts on. Set them up in your system settings (Ubuntu: Settings → Keyboard → Custom Shortcuts) with the commands select-reader --read, --pause and --stop.

Features

Voice, speed and volume
Pick a voice and press Preview to hear it. Volume changes right away, even mid-sentence.
Save audio
Top right of the player. Saves the text as a WAV file.
Recent
The last 10 texts; click one to read it again (also in the tray menu). Forgotten when you quit.
Start when I log in
Under Advanced. Select Reader then waits in the tray, without opening this window.
Say words differently
Under Advanced. For names and abbreviations the voice gets wrong, e.g. "kubectl" → "cube control". Leave "say" empty to skip a word, like "[1]".
Start speaking before the whole text is ready
Under Advanced. Speech starts after the first sentence; the rest is made while it plays.

From other programs

Command line (if Select Reader is running, the command goes to it):

select-reader --read          read the selection
select-reader --text "Hello"  read some text
select-reader --pause         pause or resume
select-reader --stop          stop
select-reader --hidden        start in the tray

Local web address, for scripts and browser extensions:

http://127.0.0.1:4040/read?text=Hello
http://127.0.0.1:4040/pause
http://127.0.0.1:4040/stop
